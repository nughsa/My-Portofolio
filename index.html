Tentang Saya.

Saya merupakan fresh graduate S1 Teknik Informatika Universitas Mercu Buana dengan IPK 3,69. Ketertarikan saya pada pengolahan data berawal dari pembelajaran Data Science selama perkuliahan, yang memperkenalkan saya pada eksplorasi data, analisis, serta dasar-dasar Machine Learning. Dari pengalaman tersebut, saya semakin tertarik mendalami bidang analisis data dan ingin memulai karier profesional sebagai Data Analyst.

Saya memiliki pengalaman 1 tahun 2 bulan sebagai Data Administrative di Fakultas Teknik Universitas Mercu Buana serta telah mengikuti Pelatihan Data Analyst di PPKD Jakarta Barat selama 160 JPL. Saya mengembangkan keterampilan Python, Pandas, SQL, PostgreSQL, dan Google Looker Studio melalui berbagai proyek data cleaning, analisis, dan pembuatan dashboard. Saya ingin terus mengembangkan kemampuan dalam mengolah data menjadi informasi dan insight yang bermanfaat bagi pengambilan keputusan bisnis.
